# Smartest in Iberia — GitHub Pages

Готовая статическая версия игры 4Story для размещения на GitHub Pages.

## Как опубликовать

1. Создайте новый **Public**-репозиторий на GitHub (например, `smartest-in-iberia`).
2. Откройте репозиторий → **Add file** → **Upload files**.
3. Загрузите **файлы из этой папки** (`index.html`, `.nojekyll`, `README.md`) в **корень репозитория** и нажмите **Commit changes**. ZIP-файл загружать в репозиторий не нужно — его следует предварительно распаковать.
4. Откройте **Settings → Pages → Build and deployment**.
5. Выберите **Source: Deploy from a branch**, **Branch: main**, **Folder: /(root)** и нажмите **Save**.
6. После публикации сайт откроется по адресу `https://ВАШ_НИК.github.io/smartest-in-iberia/` (если репозиторий так назван).

Если `index.html` находится не в корне выбранной папки, GitHub Pages не сможет открыть игру по главному адресу.

## Работа шоу

- Ведущий открывает ссылку на игру и управляет вопросами на своём компьютере.
- Для зрителей Discord используйте кнопку **Stage window / Окно эфира** и транслируйте только это окно.
- Состояние, очки и изменённые имена хранятся **локально в браузере ведущего**. Это НЕ общий многопользовательский сервер: другие пользователи, открывшие ссылку, получат самостоятельную локальную партию.
- Сохранение из старого локального HTML **автоматически не переносится** на домен GitHub Pages. Банк вопросов и изображения уже встроены; экспорт/импорт JSON предназначен для данных банка вопросов, а не полного прогресса партии.
- Сайт GitHub Pages общедоступен. Ответы содержатся в исходном HTML, поэтому участникам нельзя просматривать исходный код или открывать пульт ведущего.
- Интернет необходим при открытии GitHub Pages; после загрузки внешних зависимостей в игре нет.

## Состав

- `index.html` — полная игра: 13 категорий, 65 вопросов, финал, три секрета, 8 языков, портреты, логотип, скриншоты, аудио и анимация.
- `.nojekyll` — отключает обработку Jekyll при размещении на GitHub Pages.
- `README.md` — инструкция по публикации.
